# homebrew-tap

Homebrew tap for [zfogg](https://github.com/zfogg)'s tools.

## Usage

```bash
brew tap zfogg/tap
brew install spaniel
```

Or in one shot:

```bash
brew install zfogg/tap/spaniel
```

## Available formulae

- **[spaniel](https://github.com/zfogg/spaniel)** — local OpenTelemetry collector and viewer
